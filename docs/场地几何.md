# 场地几何说明

> 这份文档解释小助手里的地图数据从哪来、每个数字是什么意思。
> 真值源是 [`data/map_spec.json`](../data/map_spec.json)；本页是给人读的摘要。

## 1. 坐标系

- 单位：**cm**。
- 原点：场地**左下角**。
- x 向右，y 向上（数学坐标，不是图片坐标）。
- 朝向：0° = +x（右）、90° = +y（上）、180° = −x（左）、270° = −y（下）。

## 2. 场地与标定

| 项 | 值 |
|---|---|
| 场地 | **220（宽）× 120（深）cm** |
| 引导线 | 黑色，宽 **2–3 cm**（图上按 2.5 cm 建模） |
| 基地 | **30 × 30 cm**，底部中央，中心 (108.30, 15.50) |
| 模型位 | 10 个：01–10；模型区 16×8 或 8×16 cm |
| 图片标定 | `地图.jpg` 1265×696 px；边界 x=11..1252、y=8..685 → **5.641 px/cm** |

像素复核结果：11 条粗线中心、13 个节点、基地外沿、10 个模型区与图差 **≤ 0.2 cm**。
所以本页的几何值可以直接当数据源。

## 3. 22 个节点 / 21 条边

地图把黑线抽象成 **22 个节点、21 条边**：

- **19 条引导线**（kind=`line`）
- **1 条基地段**（kind=`base`，BTOP–BASEC）
- **2 条脱线段**（kind=`free`，基地→07 / 基地→08）

### 3.1 三段线网 + 一条基地段

> 这里要修正一个常见简化：不是“左右两个网”，准确说是 **3 段互不连通的引导线**，再加基地段/脱线段。

| 线网 | 包含 | 怎么进 |
|---|---|---|
| **左网** | 10 → J01 → J02 → J03 → 03；01/02 从 J01/J02 上去；J03 → JH5 → JV6 → BTOP → 基地；V1E/H5E 是无模型死端 | 基地沿 V6 向上，**有黑线** |
| **右网** | 04 → J05 → 05；J05 → J06 → 06；J06 → 07 | 基地→07 **脱线 F01 = 62.0 cm** |
| **08-09 支线** | 09 → J09 → 08 | 基地→08 **脱线 F02 = 50.3 cm** |

关键结论：

1. 左网、右网、08-09 支线之间**没有黑线相连**。
2. 任何跨线网的转场都**必须经过基地**（或至少回到基地附近再脱线）。
3. 所以路线天然分成“多趟（trip）”：每趟从基地出发，访问若干模型位，再回基地。

## 5. 23 个实测参数

用户尺量了 23 个数，与几何逐条比对：

| 分级 | 数量 | 说明 |
|---|---|---|
| 正常（|Δ| ≤ 1.5 cm） | 13 | 与几何吻合 |
| 警告（1.5 < |Δ| ≤ 3） | 5 | 多为“从粗线内边缘量”少一个线宽 |
| 错误（|Δ| > 3） | 4 | 旧版 200×100 场地、端点量错等 |
| 待确认 | 1 | #10 含义未确认 |

结论：**规划/页面一律用几何值**；23 个原值保留在 `map_spec.json → params` 里供核对。
完整明细见 [`参数差异报告.md`](参数差异报告.md)。

## 6. 这套几何怎么用

- 页面上的 01–10 圆点：模型位的巡线终点（`S01..S10`）。
- 页面上的橙色虚线：两条脱线段（基地→07、基地→08）。
- 页面上的绿色虚线框：30×30 cm 基地。
- 页面上的 22 个节点：引导线路口/模型位终点/死端/基地。

## 7. 证据与边界

- 几何：官方场地图像素标定 + 复核，误差 ≤ 0.2 cm。
- 23 参数：尺量值与几何值的差异已归因；页面以几何为准。
- 模型朝向：05–10 与图自洽；01–04 为推断，需现场确认。
- 计分：页面只做“任务/出发/返回/自主”的算式；裁判判罚、超时、犯规不在计算内。
