# 赛规速查（2026 普及赛 · 伙伴机器人）

> 这是参赛队自己整理的速查，不是官方规则原文。**最终以 [`assets/2026年赛规.pdf`](../assets/2026年赛规.pdf) 和裁判现场解释为准。**

## 1. 一场比赛

| 项 | 内容 |
|---|---|
| 主题 | 伙伴机器人（医院 / 健康场景） |
| 场地 | 220 cm（宽）× 120 cm（深），黑色引导线 |
| 基地 | 30 × 30 cm，底部中央；机器人可多次往返 |
| 单场 | **180 秒** |
| 赛前准备 | **90 分钟**；3 个现场任务此时公布 |
| 模型位 | 01–10；模型/任务在开赛前随机摆放并公布 |
| 机器人 | 出发前 ≤ 30×30×30 cm；≤ 4 个电机；禁数字舵机；塑料拼插结构；电池 ≤ 9V |

## 2. 任务与分值

| 任务 | 分值 | 说明 |
|---|---|---|
| 出发 | 30 | 按“第一次离场”计一次（我们的理解） |
| 返回基地 | 30 | 按“最后一次回基地”计一次（我们的理解） |
| 扶起老人 | 50 | 把倒下的老人模型扶起 |
| 自动取药 | 50 + 50 | 推杆让药丸掉入药框 50；把药丸带回基地 50 |
| 用药提醒 | 50 + 50 | 打开药盒盖 >90° 得 50；把“自动取药”带回基地的药丸放入药盒再得 50 |
| 活动健身 | 50 | 转柄使小人空中旋转 ≥1 圈 |
| 现场任务 1/2/3 | 各 100 | 赛前 90 分钟公布 |
| 自主运行奖励 | 40 − 10 × 重启次数 | 最低 0 |

**满分示例**：600（任务）+ 30（出发）+ 30（返回）+ 40（自主）= **700 分**。

## 3. 跨任务依赖（最容易丢分）

```
自动取药：药丸掉入药框（+50）
        ↓ 必须把药丸带回基地（+50）
用药提醒：开盖 >90°（+50）
        ↓ 把带回的药丸放入药盒（+50）
```

- 合法顺序必须是「取药点 → 回基地交付 → 用药点」。
- 如果跳过“回基地交付”，用药提醒最多只能拿 50 分。
- 页面右下角的“药丸已带回”勾选框就是用来模拟这个条件的。

## 4. 场地结构

- 22 个节点 / 21 条边：19 条引导线 + 1 条基地段 + 2 条脱线段。
- **3 段互不连通的引导线**：左网（接基地）、右网（04–07）、08-09 支线。
- 右网与 08-09 支线没有黑线连接：基地→07 脱线 62.0 cm，基地→08 脱线 50.3 cm。
- 左网 / 右网 / 08-09 支线之间的任何转场都要经过基地 → 路线天然分成多趟。
- 死端 V1E、H5E 没有模型，路线不会主动去。

详见 [`场地几何.md`](场地几何.md)。

## 5. 现场 5 分钟流程

1. 拿到“任务 → 模型位”的分配表。
2. 在小助手右侧把 7 个任务的下拉框选好；同一模型位不能重复。
3. 看预计得分与依赖提醒，决定做哪些、跳过哪些。
4. 按模型位和朝向核对动作；模型正面朝向以现场红箭头/实物为准。
5. 上场前确认出发、返回、重启次数和药丸交付。

## 6. 计分口径说明

页面里的计分是**我们自己按公开资料整理的算式**，用于赛前快速估算：

- 出发 30 按“第一次离场”计一次；
- 返回 30 按“最后一次回基地”计一次；
- 自主奖励按 40 − 10 × 重启次数；
- 自动取药/用药提醒的追加分按“药丸回到基地/放入药盒”计；
- 不含超时、犯规、重试失败等判罚。

这些细节如果和裁判口径不同，以裁判为准。页面只帮助做“做哪些任务、大概多少分”的决策。

## 7. 安全

- 第一次试跑先架空轮子，手放在电源开关附近。
- 速度从低开始，机构动作先确认限位。
- 程序要有超时保护：超时先停车，再回基地。
- 比赛前确认电池电压、轮子/螺丝、传感器接线。
