# 数据来源、可信度与边界

## 1. 地图数据

| 项 | 来源 |
|---|---|
| 场地尺寸 | 2026 年赛规：地膜 220 × 120 cm |
| 引导线宽 | 赛规 2–3 cm；图上按 2.5 cm 建模 |
| 基地 | 赛规 30 × 30 cm；图上外沿 29.6–29.7 cm |
| 像素标定 | `地图.jpg` 1265×696 px；边界 x=11..1252、y=8..685 → 5.641 px/cm |
| 节点/边 | 从黑线像素骨架 + 人工核对得到 22 节点 / 21 边 |
| 模型区 | 16×8 / 8×16 cm 细线矩形 + 8×16 接近通道 |

**复核结果**：11 条粗线中心、13 个节点、基地外沿、10 个模型区与图差 ≤ 0.2 cm。
所以页面直接用几何值，不拿尺量值反推几何。

## 2. 23 个实测参数

用户提供的 23 个尺量值（原图：[`assets/地图标注结果.jpg`](../assets/地图标注结果.jpg)）与几何逐条比对：

| 分级 | 数量 | 典型原因 |
|---|---|---|
| 正常 | 13 | 与几何吻合（|Δ| ≤ 1.5 cm） |
| 警告 | 5 | 多为从粗线**内边缘**量，少一个线宽（约 2.5 cm） |
| 错误 | 4 | #21/#22 疑按旧版 200×100 场地量；#5 端点/分段量错；#12 少 3 cm |
| 待确认 | 1 | #10 含义未确认 |

**结论：规划/页面一律用几何值。** 23 个原值保留在 `map_spec.json → params` 里供核对，不删不改。
完整表格：[`参数差异报告.md`](参数差异报告.md)。

## 3. 模型朝向

- 05–10：红标记位置与“朝场内”规则自洽。
- 01–04：图上红箭头只有约 1.5 cm，无法判读箭头尖方向；按“红标记在模型区靠场内一侧”推断为 **270°（朝下/场内）**。
- **现场以实物红箭头为准**；如果 01–04 的方向不同，只影响“到点后怎么转正”，不影响本页的分配/计分。

## 4. 计分

- 分值来自赛规计分表与公开资料。
- 出发/返回/自主奖励的判定细节（例如“第一次离场”“最后一次回基地”）是我们的理解，需裁判确认。
- 页面只做“任务分 + 出发 + 返回 + 自主”的加法；**不含**超时、犯规、重试失败、机构未完成等判罚。

## 5. 这个页面不做什么

- 不做路线规划/自动生成程序（那是另一个更大的工具）；
- 不做真实计时（180 秒是比赛预算，不是页面倒计时）；
- 不替代官方赛规和裁判解释；
- 不修改任何地图源文件（页面只读，分配结果可导出 JSON）。

## 6. 可复现

```bash
# 重新生成 data/map-data.js 和 data/params.js
python tools/build_data.py

# 校验 22 节点 / 21 边 / 10 模型位 / 3 段线网 / 23 参数
python tools/validate_data.py

# 无服务器 UI 测试（Playwright，file:// 打开）
python tests/test_ui.py
```
